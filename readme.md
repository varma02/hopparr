# Hopparr

Simple media management for your self-hosted streaming service.

## The plan

1. Start out as a simple CLI tool to manage media libraries
2. Turn that into a more TUI like experience
3. Build an API around it
4. Make a jellfin plugin
5. Create an interface first for the web than mobile and tv apps
6. Make it a full fledged media server like jellyfin
7. Profit ?

## Features

- Manage multiple libraries of different types (movies, tv shows, music, etc.)
- Fetch metadata and images from various sources (TMDB, TheTVDB, MusicBrainz, etc.)
- Organize media files into a consistent folder structure compatible with jellyfin
- Monitor libraries for new releases and torrent availability
- Download media files via an external torrent client (qBittorrent, Transmission)
- Provide a simple CLI interface for managing libraries and downloads
- Configurable settings via a file or environment variables
